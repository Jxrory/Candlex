# Triage Labels

技能使用五个标准 triage 角色。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| 角色 | 本仓库中的标签 | 含义 |
|------|---------------|------|
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告人补充信息 |
| `ready-for-agent` | `ready-for-agent` | 定义完整，可供 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

当技能提到某个角色（如"应用 AFK-ready triage 标签"）时，使用本表中对应的标签字符串。

如你实际使用的标签名称不同，请修改右侧列。
